# Project Roadmap

## Phase 1: Project Setup and Initial Architecture
- **Microservices:**
  - Define and document microservices architecture.
  - Set up initial project structure with Maven for Java Spring Boot.
  - Configure Docker for containerization.
  - Set up Kubernetes for server management.
  - Configure Jenkins for deployment.
  - Set up Redis for caching.
  - Configure Elasticsearch for main product search.
  - Set up Oracle database with the provided credentials.
  - Configure OAuth 2.0 for authentication.

- **React Front-ends:**
  - Set up initial React project structure.
  - Configure environment variables for development, production, and local environments.
  - Implement basic UI components (e.g., Navbar, LanguageDropdown).
  - Implement responsive design for mobile phones and tablets.
  - Implement light and dark mode themes.
  - Implement initial routing and navigation.

- **Database Integration:**
  - Set up database schema for Oracle.
  - Implement initial data models and entities.
  - Implement basic CRUD operations for initial entities.
  - Implement soft delete functionality.
  - Implement multi-language support with initial languages (Turkish and English).

## Phase 2: User and Authentication System
- **Microservices:**
  - Implement user authentication and authorization microservice.
  - Implement user registration and profile management.
  - Implement ID verification system with dummy page.
  - Implement permission management system.

- **React Front-ends:**
  - Implement user login and registration pages.
  - Implement user profile page.
  - Implement ID verification page.
  - Implement permission management pages for admins/moderators.

- **Database Integration:**
  - Implement user and permission tables.
  - Implement ID verification and application tables.
  - Implement logging for user activities.

## Phase 3: Product Management System
- **Microservices:**

  - Implement seller management system.

- **React Front-ends:**

  - Implement seller management pages for admins/moderators.
  - Implement seller application page.

- **Database Integration:**

  - Implement logging for product activities.

- **React Front-ends:**

## Phase 6: Testing and Deployment
- **Microservices:**
  - Implement unit tests for all microservices.
  - Implement integration tests for microservices.

  - Implement unit tests for React components.

- **Deployment:**
